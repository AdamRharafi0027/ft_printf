# ft_printf

## Description

> ft_printf is a custom implementation of the standard C `printf()` function, developed as part of the 42 curriculum.

The goal of this project is to recreate the behavior of `printf()` by handling variadic arguments and formatting different types of data.

This project helps develop a deeper understanding of C programming concepts, including variadic functions, pointers, memory representation, data conversion.

## Instructions

### Installation

Installing the `make` tools:

**Windows**
```bash
winget install ezwinports.make
```

**Linux** (Debian/Ubuntu)
```bash
sudo apt update
sudo apt install make
```

**macOS**
```bash
xcode-select --install
```

### Compilation

To compile the library, run the following command at the root of the repository:

```bash
make
```

This will generate the static library `libftprintf.a`.

### Make commands

```bash
make        # Compiles the library
make clean  # Removes object files
make fclean # Removes object files and libftprintf.a
make re     # Rebuilds the library from scratch
```

### Usage

Include the library header in your C source file:

```c
#include "ft_printf.h"
```

Use `ft_printf()` in your program:

```c
int main(void)
{
    ft_printf("Hello, %s! You are number %d.\n", "42", 42);
    return (0);
}
```

Compile your program with the library:

```bash
cc main.c -L. -lftprintf -o program
```

Run the program:

```bash
./program
```

## Conversion Specifiers

The `ft_printf` function supports the following mandatory conversion specifiers:

> **Character Conversion**

- **%c** : Prints a single character.

> **String Conversion**

- **%s** : Prints a string.

> **Pointer Conversion**

- **%p** : The `void *` pointer argument has to be printed in hexadecimal format.

> **Signed Integer Conversions**

- **%d** : Prints a decimal (base 10) number.
- **%i** : Prints an integer in base 10.

> **Unsigned Integer Conversion**

- **%u** : Prints an unsigned decimal (base 10) number.

> **Hexadecimal Conversions**

- **%x** : Prints a number in hexadecimal (base 16) lowercase format.
- **%X** : Prints a number in hexadecimal (base 16) uppercase format.

> **Percent Conversion**

- **%%** : Prints a percent sign.

## Technical Concepts

This project introduces and reinforces several important C programming concepts:

- **Variadic Functions** : Using `va_list`, `va_start`, `va_arg`, and `va_end` to handle a variable number of arguments.
- **Format Parsing** : Reading the format string and identifying conversion specifiers.
- **Type Conversion** : Handling signed integers, unsigned integers, characters, strings, pointers, and hexadecimal values.
- **Number Conversion** : Converting numbers into decimal and hexadecimal representations.
- **Return Value** : Returning the total number of characters printed, as `printf()` does.
